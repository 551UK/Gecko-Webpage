# Gecko-Webpage

**Gecko-Webpage** turns websites into full-screen, app-like experiences using the **Firefox Gecko engine** via [Reynard Browser](https://github.com/minh-ton/reynard-browser), rather than Safari's WebKit.

It's particularly useful on **older iOS versions**, where official apps may be outdated, unsupported or limited. Websites such as eBay, Google, Discord and ChatGPT can look and feel more like native apps, although website functionality may differ.

## Features

- **Full-screen browsing:** No normal browser address bar, tabs or toolbars.
- **Gecko engine:** Helps modern websites work on older iOS versions.
- **Automatic session restoration:** Opening the app normally returns to the page you left open.
- **Two Home Screen long-press (3D Touch / Haptic Touch) options:**
  - **Change Website:** Opens the app with a URL prompt to save and load a new homepage.
  - **Start New Session:** Opens your saved homepage directly, without clearing cookies, logins or browser history.

The options appear when you **press and hold the app icon on the Home Screen**, not through a gesture inside the app. iOS may also show its standard Home Screen actions.

## Multiple instances

[**Four separate IPAs are available in Releases**](https://github.com/551UK/Gecko-Webpage/releases), each with a different bundle ID. Install **Gecko WebApp 1, 2, 3 and 4** side by side, each with its own browsing session and app data.

You can also use compatible iOS tweaks to **change each app's icon and displayed name**, making it resemble the native app you want to mimic. These appearance changes do not add native-app functionality.
